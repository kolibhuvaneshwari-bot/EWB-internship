This is a responsive personal portfolio website built with only HTML5 and CSS3. It has a sticky navigation bar, a hero section, About, Skills, Projects, Contact and Footer sections, with anchor links that jump to each section. I used semantic tags (header, nav, main, section, article, footer), CSS variables for the colour palette, Flexbox for the navigation and skill chips, and CSS Grid for the About and Project cards. Buttons, links, skills and project cards have hover and focus states, and media queries at 900px and 600px make the layout work on tablet and mobile with no horizontal overflow.
